|-----------|-----------|-------------|--------|-----------|

| 14B | 14B | A100-40GB / 2× L4 | QLoRA (4-bit) | ~$2/hr Modal |
| 32B | 32B | A100-80GB | LoRA (8-bit) | ~$3.40/hr Modal |
| 72B | 72B | 2× A100-80GB | QLoRA (4-bit) | ~$7/hr Modal |

**Recommended: Qwen2.5-Coder-7B on Kaggle L4** — fits in 4-bit QLoRA with 
group_size=8 for GRPO. Free GPU, can train for hours.

## Training Pipeline

```
1. python finetune_qwen.py --mode inspect --model Qwen/Qwen2.5-Coder-7B
   → Verifies model loads correctly

2. python self_play_data.py --qwen --model Qwen/Qwen2.5-Coder-7B --n 50
   → Generates self-play training data (SSR-style)

3. python finetune_qwen.py --mode rlvr --model Qwen/Qwen2.5-Coder-7B \\
     --n-steps 500 --group-size 8 --lr 2e-5
   → GRPO training with proportional rewards

4. python eval_qwen.py --model Qwen/Qwen2.5-Coder-7B --ckpt ./qwen_rlvr --mode humaneval --limit 164
   → Full HumanEval evaluation

5. python agent_qwen.py --model Qwen/Qwen2.5-Coder-7B --ckpt ./qwen_rlvr "solve this task"
   → Agent loop test

6. python eval_qwen.py --model Qwen/Qwen2.5-Coder-7B --mode agent --n-samples 16 --limit 20
   → Agentic eval with test-time compute scaling
```

## Key Innovations Applied

1. **Self-play data** (SSR, ICML 2025): Generate bug-inject/fix pairs
2. **GRPO with proportional rewards** (DeepSWE): Dense RL signal
3. **Test-time scaling** (--n-samples 16): +~17% SWE-Bench gain
4. **Our verifier** (verify/verifier.py): Per-test granular rewards

## Dataset: Fable5 Agentic Coding SFT

The dataset `Nexlab/fable5-agentic-coding-sft` contains **160k rows** of
agentic coding traces generated by Claude Fable 5, covering:
- Game development (prototypes, 3D rendering)
- Tool/utility building
- Shell scripting and automation
- Code debugging and repair
- Frontend development

Format: Standard `messages` array with `role`/`content` keys (chat format).

## Quick Start (Plug and Play)

```bash
# One command — downloads Fable5 data, trains SFT, then RLVR:
python train_qwen.py

# SFT only (faster, ~2-4 hours on L4):
python train_qwen.py --sft-only --limit 10000

# Full 160k rows (overnight run):
python train_qwen.py --sft-epochs 2 --batch-size 4
```
